# 提案：軟體工程師改為第一人稱視角＋漸黑過場（已核准，2026-10-23；已實作 v0.11）

## 決定
- **移動方式**：地點之間漸黑傳送。按「前往○○」或「帶我去」時，畫面漸黑約 0.4 秒，在新地點漸亮。鏡頭在眼睛高度，面向要找的人或物件。
  - 可以拖曳畫面左右環顧，桌機也可以用左右方向鍵。上下角度鎖在小範圍內。
  - 不能用方向鍵自由走動，也不能點地板移動。
- **範圍**：先做軟體工程師；老師和水電工維持俯瞰，列入待辦。
- **背景**：首頁和猜測、對照、結果畫面維持俯瞰環繞。按「開始這一天」時，先漸黑再進入第一人稱視角。
- **自己**：畫面上看不到自己，不顯示手或身體。
- **場景**：補上天花板與四面牆，讓第一人稱視角不會看到場景外面。俯瞰時隱藏這些物件，維持剖面效果。
- **規則不變**：同一群組內換地點照樣 +5 分鐘；「！」標記、名牌、地點標籤照常顯示；可以點畫面中的人或「！」選擇事件。
- **減少動態**：漸黑改為直接切換，環顧不加慣性。

## 實作（v0.11）

## 追加決定：文字 RPG 框架（2026-10-23，HP11；已實作 v0.12）
使用者指示：「第一視角的遊戲框架偏向文字 RPG，遊戲中的任務與遊戲畫面嵌合」。決定採用「對話框＋畫面內任務」，不逐字打字。範圍限軟體工程師的遊玩畫面，其他職業與首頁、猜測、對照、結果畫面不變。

- **版面**：手機與桌機都讓場景鋪滿畫面，取消左側或底部的大面板。
  - **上方 HUD**：時鐘、剩餘倒數、狀態徽章、精力／時間／信任三個小條，以及「回到選單」「全螢幕」。
  - **下方對話框**：半透明深色底，約佔畫面高度 30%，可捲動。框上方有名牌，顯示說話者（例如「產品經理」「主管」；旁白顯示「你」或不顯示名牌）。內文沿用現有的分頁，按「繼續」翻頁。
- **選項**：做成對話框內的回應列表，例如「▸ 評估後說明要另開 ticket」。代價（效果數值）在選完後的結果頁顯示，維持現有規則。
- **說話者**：事件新增選填欄位 `speaker`（劇本內容）。沒有填的事件以地點的主要人物或旁白呈現。
- **畫面內任務**：小遊戲和查資料不再用獨立面板。
  - 「你的螢幕」任務（code review、除錯、寫測試、線上告警查資料）：鏡頭推近到座位螢幕，任務介面顯示在螢幕框內（螢幕形狀的 DOM 疊層，對齊螢幕投影位置），完成後鏡頭拉回。
  - 會議室大螢幕：技術分享會等。
  - 其他地點的事件：畫面上方顯示文件或手機樣式的疊層。
- **待辦清單**：同時有多件事時，對話框顯示「今天要處理的事」列表，地點不同的事件標註地點，按下去就漸黑過去。
- **打斷事件**：來電顯示為畫面上方的手機來電卡，有人走過來則顯示為對話框，名牌是來的人。
- **一併修正 HP11 的瑕疵**：
  - 地點標籤只在看得到（沒有被牆擋住）時顯示。
  - HUD 避開全螢幕按鈕。
  - 補一點燈光與材質變化（不加貼圖檔，仍是程式產生）。
- **無障礙**：對話框可以用鍵盤操作（Enter 繼續、數字鍵選選項），名詞解釋照舊可以點。

### 實作（v0.12）
